# 状态术语

界面和日常说明统一使用下列中文名称。原始事件名保持原样；英文状态码只属于程序接口、文件字段和原始审计数据，不直接作为界面标签。

## 四个独立维度

| 维度 | 中文术语 | 含义 |
| --- | --- | --- |
| 支持级别 | 稳定支持 | 精确语义模式已接受，且满足对应的质量要求 |
| 支持级别 | 试验支持 | 保留解释和证据，但尚未纳入稳定支持范围 |
| 支持级别 | 暂不支持 | 当前没有提供对应能力 |
| 中文生成 | 已生成 | 正式生成器已产生解释，不代表语义已审阅或数据集已批准 |
| 中文生成 | 回退显示 | 使用了回退词条或不完整的解释 |
| 中文生成 | 缺少解释 | 尚无可用的正式解释 |
| 中文生成 | 不适用 | 该类记录不适用正式中文生成 |
| 模式审阅 | 已接受 | 对应语义模式的审阅决定已接受 |
| 模式审阅 | 待审阅 | 对应模式尚需审阅 |
| 模式审阅 | 已拒绝 | 对应审阅决定未接受 |
| 模式审阅 | 暂缓 | 当前暂缓纳入支持范围 |
| 数据集状态 | 待审候选 | 一份可供审阅、尚未批准的生成结果 |
| 数据集状态 | 检查未通过 | 生成结果存在阻断检查问题，仅供诊断和修正 |
| 数据集状态 | 本地已批准 | 已批准指针指向的精确数据集，默认消费者可读取 |

Demo 另有“已确定”和“待反馈”两个语义筛选状态。“已确定”表示解释已生成且没有记录警告、校验问题或归属问题；“待反馈”表示仍存在这些缺口。它们与支持级别、模式审阅、数据集批准分别判断。

新增对象、条件或其他语义角色可能形成新的模式，即使相近模式以前已接受，也须按新模式重新判断。查不到可靠映射的编号继续保留为未知，并显示待反馈，不为减少未知数量猜测名称。

## 程序接口对照

本表只用于接入和调试，界面使用左列中文。字段和枚举保持现有兼容性。

| 中文术语 | 字段或程序值 |
| --- | --- |
| 稳定支持／试验支持／暂不支持 | `support_level`: `stable` / `experimental` / `unsupported` |
| 已生成／回退显示／缺少解释／不适用 | `render_status`: `rendered` / `fallback` / `missing` / `not_applicable` |
| 已接受／待审阅／已拒绝／暂缓 | `review_status`: `accepted` / `pending` / `rejected` / `deferred` |
| 已确定／待反馈 | `semantic_status`: `determined` / `feedback` |
| 本地已批准 | `approved_local`；权威指针文件仍为 `dist/runs/approved-local.json` |

“已接受”描述模式审阅决定，“本地已批准”描述整个数据集，两者不可混用。身份标识、内容摘要和事件原名作为证据值保留，不将它们翻译成新的标识。
